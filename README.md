# SI-BEL Sekolah
Sistem Informasi Beasiswa dan Lomba Sekolah.

## Isi repository
- `index.html` — struktur halaman login
- `style.css` — tampilan dan desain responsif
- `script.js` — interaksi tampil/sembunyikan password dan pesan formulir

## Menjalankan
Buka `index.html` melalui browser, atau unggah seluruh file ke repository GitHub.

## Mengaktifkan GitHub Pages
1. Buka repository GitHub.
2. Pilih **Settings** → **Pages**.
3. Pada bagian **Build and deployment**, pilih **Deploy from a branch**.
4. Pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
5. Tunggu proses publikasi, kemudian buka alamat GitHub Pages yang ditampilkan.

## Catatan
Halaman ini merupakan prototipe antarmuka login. Form belum memverifikasi akun atau menyimpan password. Untuk login sungguhan, hubungkan ke backend atau layanan autentikasi yang aman. Jangan menyimpan password asli di JavaScript atau repository publik.
